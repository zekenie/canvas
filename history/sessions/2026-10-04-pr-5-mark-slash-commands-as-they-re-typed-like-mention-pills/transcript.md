## Description

## What

A `/name` typed on a line was plain text until Return ran it. Now it's marked the way a mention is: a rounded background behind the text, the height of a mention pill, in the text's own color so it follows whatever surface it's on (a note's yellow, the panel's neutral).

- **`/name`**: a firmer shade (18% of the text color; a pill is 10%).
- **What it's given** (`/title Groceries` → `Groceries`): a lighter shade of the same (8%).

It marks the line the caret is on:

- while the `/` list is open and lists a command for what's typed (`/` alone, `/wid`, …). "No matches" marks nothing.
- with the list closed (after a space, Tab, or Escape), as long as the shape offers that command right now. This is the same line Return would run.
- the arguments are marked only if the command accepts them, so `/lock now` marks `/lock` alone, and `now` stays plain text.
- nothing in a view that can't be written (locked).

The note on the canvas when *not* being edited is unchanged. This is for the editing view, which is also the panel's mention boxes and a schema card's description.

## How

- **TextEditing**: `EditingTextView.highlights` (`[TextHighlight]`: a range and a fill), drawn in `drawBackground` next to the placeholder. `frames(of:)` says where (a rect per line, TextKit 2 only, like `caretFrame`). Made read-only, the view lets go of them. A host forwards nothing.
- **SlashCommands**: `SlashCommandTyping` sets them after each text/caret change. `SlashCommandLine.nameRange` is new (the `/` and the name). The two strengths are `SlashCommandStyle.commandFill` / `argumentsFill`, so they're easy to tune.
- Docs updated in `CLAUDE.md` and `docs/plugin-system.md` ("Marking the command").

## Not built or run

This was written in a cloud environment with no Swift toolchain. Nothing here has been compiled or run, including the new tests (`SlashCommandsTests`, `MentionsTests` `slashTests`, new `TextEditingTests` Highlights suite). `./test.sh` first; I'd expect, if anything, small compile fixes.

## Testing by hand

1. `./build.sh && open build/InfiniteCanvas.app`, then add a note and start typing in it.
2. On a new line type `/`. The list opens and the `/` gets a soft chip. Type `lo`: the chip grows to `/lo`. Type `zz`: "No matches", chip gone.
3. Type `/lock` then Escape. The list closes but `/lock` stays chipped (it's still a command Return would run). Return locks the note and the line goes.
4. Type `/title Groceries`. `/title` is the firmer chip and `Groceries` a lighter one beside it. Return names the note.
5. Type `/lock now`: only `/lock` is chipped. `/nope`: nothing.
6. Put `@` + a note after `/title ` in the line: the pill sits inside the lighter chip.
7. Move the caret to another line: the chip goes. Back onto the line after the `/`: it returns.
8. Look at it on a note (yellow), in the inspector's text boxes, and in light and dark appearance. If the chips read too faint or too strong, adjust the two constants in `SlashCommandStyle`.
