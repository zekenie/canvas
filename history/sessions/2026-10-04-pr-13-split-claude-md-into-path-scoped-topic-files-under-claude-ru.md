## Description

## Why

CLAUDE.md had grown to 297 KB, some 70K tokens, and all of it loaded into every session, whatever the task. The Claude Code docs ([memory](https://code.claude.com/docs/en/memory)) recommend under 200 lines per CLAUDE.md ("Longer files consume more context and reduce adherence") and point to path-scoped rules for "instructions that matter for only part of the codebase". `@path` imports don't help: imported files also load at launch.

A file in `.claude/rules/` whose frontmatter names `paths:` is different: Claude Code adds it to the context only "when Claude uses the Read, Write, or Edit tool on a file matching the pattern".

## What

- **`CLAUDE.md` is 12.8 KB.** It keeps what every task needs: how the instructions load, build and test, the rules for every change, what a test must never do, and a map of the topic files, a line each.
- **37 topic files in `.claude/rules/`**, one per subsystem. Each one's `paths:` names its module's sources and tests. Each starts with what it covers, then links the topics it touches (the graph) and its sections of `docs/plugin-system.md`. Then come its subsystem's paragraphs: the architecture first, then, under Testing, the paragraphs that were in "Verifying UI changes".
- **What loads, for example:**
  - reading `Sources/Mentions/MentionState.swift` adds `mentions.md` (25 KB);
  - `Sources/Frames/FrameTool.swift` adds `frames.md` (5 KB);
  - `Package.swift` adds `build.md` (10 KB).

## First commit: nothing reworded

Every paragraph of the old file is in exactly one file, unchanged except for its "above" and "below" references. Those pointed at another paragraph, and each is now a link to the file that paragraph is in.

A few rules that matter everywhere are restated in a line each in `CLAUDE.md`, with a link to the full text: layers, migrations and fixtures, keeping the canvas skill in step, tldraw, the API key, and what a test never touches. That duplication is deliberate.

- the `--ask` eval's round 1 and round 2 scores (`scripts/query-prompts/README.md` has each round's table);

## Worth knowing

- **Only Read, Edit and Write trigger a rules file.** A file read through Bash or found with Grep doesn't, so `CLAUDE.md` tells Claude to read an area's topic file from the map before working there.
- **A new subsystem** needs a topic file with `paths:` and a line in the map; `CLAUDE.md` says so.
