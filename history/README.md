# History

`sessions/` holds a directory for each Claude Code session that landed a commit on main: its
condensed transcript (`transcript.md`: what the owner asked and answered, the corrections, the
plans, and what was turned down) and the plan files it wrote (`plans/`). A commit names its record
in a `Session:` trailer. How records are made and read:
[the history skill](../.claude/skills/history/SKILL.md).
