# Drawings and `canvas apply`

What a program drew on a board's file, kept so it can see a person's changes and take another pass; `canvas apply`, a whole document drawn by key in one step; `canvas measure` of a document; `canvas draw --drawing NAME`; and the words that read a drawing (`:drawn-by("NAME")`, `:changed("NAME")`). The contracts between the layers (the app, the render layer, ingest) are the Claude Doc "Drawing in layers" (its Contracts tab).

Related: [command line](command-line.md) (`canvas draw`, `measure`, `rehearse`), [editor](editor.md) and [undo](undo.md) (a rehearsal and `adopt`), [properties and schemas](properties-and-schemas.md) (file values), [queries](queries.md), [digest](digest.md) (the render layer, which writes documents), [ingest](ingest.md) (the lens, which writes graph documents) ([every topic](../../CLAUDE.md#map)).

## Architecture

- **The document** (Draw's `Document.swift`, `DrawDocument`): JSON with `drawing` (the drawing's name), `nodes` (each `key`, unique and the same from run to run; `kind`, one `canvas kinds` says is drawable; `in`, the key of the node holding it, whose kind holds shapes or a board; `props`, attributes as `canvas draw` takes them, as JSON; `place`, where its room goes: `at` from its frame's top-left, else its board's origin, any number, and `size`) and `edges` (each `from` and `to`, keys; `key`; `props`, the arrow's attributes; `place.pill`: `{at, in}` makes the pill an edge goes through, `{share}` draws into the pill that node's own edge goes into, `for` the end it stands for, the `to` end unless it says). `layout` (anywhere) is the render layer's and read here by nothing. Where a value names a shape (a type in `is`, a mention), a node's key names it, before any title. A text attribute given an object or a list takes its JSON text (`"schema": {…}`). A script is read a line a statement and a line ends at any character Swift calls a newline, so a text's line and paragraph separators (U+0085, U+2028, U+2029) are written `\n` and JSON text's as its escapes (`DrawDocument.quotedLiteral`, `jsonOnOneLine`). Read with every problem said at once, by key (or `edges[i]`): `DocumentError` (`refusals`, each `{key | edge, reason, message, hint}`), which Automation says with `key`, `edge` and `refusals` in its data.
- **`canvas apply`** (Automation's command, `ApplyParams`: `document` on standard input, `--dry-run`, `--on NAME`; Draw's `apply(document:dryRun:on:program:in:)`, `DocumentApply.swift`): the drawing by its name, updated by key on every board it reaches, in one step (Edit › Undo Draw), all or nothing. It reads the drawing's record (`DrawRecords`, below): a key it has keeps its shape (the same kind, on the board the node goes on; a shape the node can't be, another kind or on another board, is deleted and drawn anew), any other key gets an id picked here; two edges of one key (a key given twice, or one that is another edge's key worked out) are refused by place, `duplicate`, since the record keeps an arrow by its edge's key; the drawing's shapes whose keys are gone are deleted (a subboard whose board holds a shape the drawing didn't make is refused), arrows and the pills they empty by id, but for what a `canvas draw --drawing` run joined to it (keyed by its own id, `RecordKey.joined`), which no document names and which stays, in the record too. Its top goes on the board `--on` names (a subboard by its title, a path or `#id`), else where the drawing was drawn, else the root. Then it is drawn on a rehearsal of the editor (`editor.rehearsal()`, [editor](editor.md)) in `draw`'s own runs, a board at a time (the top first, then each board whose holder is drawn), in an order only the app knows: deletes (a shape on a board another deleted shape takes with it, a subboard's at any depth, goes with that one and is no delete of its own); every node made or moved, what holds shapes before what it holds (a run a depth), named by its id (`DrawOptions.reserved`: a shape statement named `#<id>` the file hasn't makes a shape with that id) and placed exactly (`DrawOptions.places`, by the statement's line: its room's top-left, never solved, pushed or pushing); then every node's properties, one statement a node, a run a board, each saying its size and exact place again (what a node holds can lay it out otherwise than the shape it was made as: a type's instance has rows, and a relationship type is a pill about the middle of a box its words make taller, so it is placed again by the frame it is laid out in), its title written by `title:` (`DrawOptions.program`: a program's titles are what it calls shapes, never names, so a duplicate beside it is allowed), a value's key found by `DrawOptions.keys` (`DrawTextLookup`: a key before a title), and a run refused only for naming a node whose own properties aren't written yet (`DrawError.lookedFor`: a type before its schema) drawn again without those statements, which wait for a later round, so types come before their notes on whatever board; then each pill's shape made what its kind of pill needs (Topology's `standIns.fulfil`: public); then the edges, a run a board (the near end's), pill makers before the edges that share their pills (`via:` with the kind that can stand for the end, `in` the pill's frame, its place exact; `share:` the host's id, `share: true` for a host that is the edge's own end), straight arrows last; then each pill an edge drew before put where the document says now (`placePills`: into the frame `place.pill.in` names, or onto its board, at `place.pill.at`, since a run that finds an edge drawn already places nothing; the edge's `did` then `updated`); then a dry run of every node as it is, for what each still needs (`problems`); then every issue of the drawing's own shapes as the copy leaves them (`sayIssues`: each node's, then each edge's arrow's and pill's, once); then the drawing's record, written in the rehearsal. An edge the drawing drew otherwise than the document draws it now (straight where it goes through a pill now, through one where it is straight now, from another board, at a node drawn anew, whose old shape a pill would go on standing for, or into a pill its group doesn't keep) is deleted first, with the pills it empties, and drawn anew, since `draw` keeps an edge as it was drawn (`via:` over one drawn straight is refused). The edges through pills come in groups, one a pill: the edge that makes it (no `share`) and those that share it, by the near end they share and the end it stands for; which of a group the plan calls its maker is the plan's to pick, so a group keeps the pill its maker's arrow runs into, whichever it picks (a pill is the group's whose edge the record keeps it under, else the first group whose maker runs into it), and an arrow in another group's pill (a group the plan split, merged or gave another host) is drawn anew. The record keeps a pill under its maker's key, and a pill the drawing deletes takes the drawing's other arrows into it, whose edges are drawn anew too. The editor takes in what the rehearsal did as one step (`editor.adopt`, [undo](undo.md)); a file changed meanwhile is refused (`busy`), and a dry run takes nothing. The answer (`DocumentResult`): `nodes` (`key`, `did` created, updated or unchanged, `id`, none for a dry run's created, `at` its room, `overrode` what a person had changed since the drawing last wrote it that this changed again, `problems`), `edges` (by place in the list, `did`, the arrow's `id`, `via`), `deleted` (`key`, `id`: a node's, and an arrow or a pill drawn anew), `warnings` (by key or edge: what a run said that is no issue of the drawing's own shapes, a push, a near miss, an issue it brought to a shape that isn't the drawing's (on the key of the node whose statement brought it, the shape named in its message), then the issues of the drawing's own shapes as the drawing ends, each once, its key in quotes leading its message, and none of what a node still needs, which its `problems` say; what a phase said of the drawing's own shapes is left out, since a later phase may mend it (a relationship's row is empty until the edges are drawn), and so is a phase's count of more shapes: `DrawWarning.about` says which shape an issue is of, and neither it nor `countsMore` is on the wire), `on`. A refusal anywhere is the run's own, its lines mapped to keys and every `#<id>` of the document's said as its key.
- **`canvas measure` of a document** (`DocumentMeasure.swift`, `measure(document:on:program:in:namesBeyond:)`; Automation's `measure` takes one when its text starts with `{`, `MeasureAnswer`, and `--on`, a document's alone, the board apply will draw it on, else where the drawing was drawn, else the root: the names of what holds that board start every pill's place, so a pill is as wide as it is drawn there; the measure's scratch board runs a clock that never moves and holds the document's nodes before their adornments are read, so a type's chips say the document's own type): every node a statement named by an id picked for it, with every property, measured by `measure`'s own drawing (`measured(script:…options:)`), so a type's schema, `is` by key and the ends size it as a draw does; `nodes[key]` (`size`, its room; `above`; `titleWidth`, Adornments' `adornmentLeastWidth`, how wide it must be for its title's pill or tab and its chips to show whole); `pills` for each end of an edge a pill can stand for (its kind's `via`), sized where it would sit, `from` the key of the node holding the other end (`.written` seats from the document's own chains); `edges` the app would refuse between their ends (the edge maker over the two ends alone: no channel), by place; `constants`; `warnings` by key.
- **Records** (Draw's `DrawRecords.swift`: the point `DrawRecords`, at most one, `registrar.drawRecords(read:write:names:)`, and the values `DrawingRecord` (its `board`, `root` or the owner's id, and `shapes` by id) and `DrawnState` (a shape as the drawing last wrote it: `kind`, `props` (its own and added values, as `record.propertiesJSON` holds them, less where it is), `board`, `container`, `box`; `changes(from:)` says how one differs: `kind`, `board`, `frame`, `moved`, `resized`, then each property by name)). Drawings (platform, `Sources/Drawings`, on Canvas and Draw) fills it: `DrawingsPlugin` declares the file value `DrawingsProperty` (key `drawings`, `DrawingRecords`, every drawing by name), shipped after the draw engine's words. Nothing is kept on a shape, so a copy of a drawn shape isn't the drawing's; a shape the file no longer holds stays in the record (what the drawing made that is gone). `Tests/CompositionTests/Fixtures/file/drawings.v0.json` is its fixture.
- **The words that read a drawing** (Drawings' `DrawingQueriesPlugin`, id `drawing-queries`, after Queries' selection words in the shipped list; both take the drawing's name and read the file alone, `reads: .file`): `:drawn-by("NAME")`, the shapes the drawing made that the file holds, each row with `key` (its key in the drawing, `#<id>` for what a draw run joined) and `in` (the key of the drawing's shape that holds it: its frame, else the shape whose board it is on), and in the answer's `absent` what it made that the file no longer holds (`{id, key}`); `:changed("NAME")`, those of its shapes that differ from what that drawing last wrote (`DrawnState.changes(from:)`, read with the shape's kind as it is now), each row with its `key` and `in` as `:drawn-by`'s and `changed` saying how. Taking them up costs the main actor O(1) (`DrawingsFact`: the file, a value, and every kind's schema, a table the registry keeps, `registry.memo`); a drawing's shapes are read off it, in `seeds`, `matches`, `rowMembers` and `absent` (`Drawn`), one drawing at a time, so a shape two drawings hold is judged by each against what that one wrote.
- **`canvas draw --drawing NAME`** (`DrawParams.drawing`; Draw's `draw(script:…drawing:in:)`): a real run joins the drawing: every shape a row names that the board still has, every arrow and pill it drew (a row's `arrow` and `standIn`, never said), kept in the record with what it now is, keyed by `#<id>` where the drawing has no key for it, in the run's own step; a row deleted by its id goes off the record; a dry run keeps nothing; `no_drawings` with nothing that keeps them.
- **What the core lends** ([editor](editor.md), [undo](undo.md)): `editor.rehearsal()` remembers the editor and file it was made from (`rehearsed`), and `editor.adopt(_:named:byAgent:)` takes in what a rehearsal committed as one commit and one step: `DocumentDelta(from:to:on:)` (the board shown shape by shape, every other board whole, the entries that didn't read as boards, the file's values) applied as undo applies a step, but as a new step (`willCommit`, `commit(_:changes:applying:)`, `didCommit`), `byAgent`; false, changing nothing, for a rehearsal of another editor or a file changed since.

## Testing

- AutomationTests' `applyTests` (ApplyTests.swift, over tiles and pens, with a records plugin of the test's own, `TestDrawings`): made by key where the places say (negative too) in one step and taken back by one undo, the record by key; a pen's shapes from its top-left; again unchanged, a label updated, a key gone deleted, a tile outside the drawing untouched; a dry run; every refusal of a document by key at once (an `in` naming no node, a key twice, a kind with no tool, `in` a shape that holds none, a ring, no drawing name); a draw refusal by key; `no_drawings`; `draw --drawing` (kept by id in the run's step, a dry run keeping nothing), and what it joined to a program's drawing kept through that program's next apply; `measure` of a document by key.
- CanvasTests' `adoptTests` (RehearsalTests.swift): what a rehearsal did on every board and to the file's values as one commit and one step, undone and redone whole; a board it made coming and going whole; another board shown; a file changed since, another editor's rehearsal, none at all; a rehearsal that did nothing.
- CompositionTests' `applyShippedTests` (ApplyTests.swift, the shipped plugins: a type, a frame holding a note of it typed by key with a value, a note mentioning it by key, an arrow: where they go, the record, one undo; again unchanged, a text updated, a key gone deleted with its arrow, a note outside the drawing untouched; a dry run; a person's move said in `overrode`; refusals by key; a type on a subboard's board and its note on the root, the type written first), `applyRedrawShippedTests` (a pill moved in its frame and then out of it, the same pill, one undo; an edge drawn straight drawn anew through a pill and back, the pill it left deleted; a node moved to another board drawn anew with nothing left standing for the shape that went; the drawing's issues said once as it ends, every time, and one it brings to a person's note on the node that brought it; a run's warnings on the wire only their line, message, severity and attribute) and `kindsAttributesTests` (contract 1: every added property a language may write is in `canvas kinds`), `drawingQueriesTests` (`:drawn-by` rows' `key`, `in` and `at`, `absent` for what a person deleted, `:changed` saying moved and text, nothing for another drawing's name); the drawings fixture in PersistenceTests (every shipped file property).
