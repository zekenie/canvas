# Slash commands

Slash commands: a line of a shape's text that runs a command the shape offers; registering and offering them, the list at a `/`, Return, undo, and hosting them in a text view.

Related: [fuzzy matching](fuzzy-matching.md), [text editing](text-editing.md), [mentions](mentions.md), [arrows](arrows.md), [titles](titles.md), [locking](locking.md), [transform](transform.md), [moving](moving.md), [context menus](context-menus.md) ([every topic](../../CLAUDE.md#map)).

In the guide, `docs/plugin-system.md`: [Slash commands](../../docs/plugin-system.md#slash-commands).

## Architecture

- Slash commands (SlashCommands, a surface, on FuzzyMatching and TextEditing; `docs/plugin-system.md`, "Slash commands") let a line of a shape's text run a command the shape offers: a `/` typed on an empty line lists them, and a line that is `/name` and what the command takes, entered with Return, runs the command and goes from the text, leaving only what the command did. A command is contributed as a context menu item is (the `ShapeSlashCommands` point, keyed by target and name): `x.slashCommands { SlashCommand("turn-on", when: { !$0.isOn }) { lamp, _ in lamp.isOn = true } }` over the kind's props, `x.slashCommands(of: P.self) { … }` over an added property's value on the kind's shapes that hold one, `registrar.slashCommands(K.self) { … }` for another plugin's kind, `registrar.slashCommands(of: P.self) { … }` on every shape that has the property, and `registrar.slashCommandsForEveryShape(where:) { … }` over the record, where `where` gets a `SlashCommandKind` (the kind, its definition, the registry and `holds(P.self)`, asked once per kind, so a feature's every-shape command goes only on the kinds that opted into it: `$0.holds(LockedProperty.self)`); a horizontal's opt-in sugar may call these, so opting in brings its commands; the builder is `MenuBuilder`'s. A `SlashCommand<Value>` is a name, an `argument` (the hint beside the name in the list, `"title"` or `"@shape"`, which also says it takes one; nil for none), `when:` (the shapes that offer it, always by default), `accepts:` (which arguments it can run with: by default none for a command without an `argument` and anything but nothing for one with; given, it replaces that rule entirely) and an action in the forms of `MenuItem`'s: `edit: { value, arguments in … }` on the shape's live value in one transaction (setting what's there commits nothing), or `perform: { id, arguments, editor in … }` for what editing can't do (locking, moving, putting somewhere), which changes the document only through `editor.transact`. A name is lowercase ASCII letters and digits, words joined by single hyphens (`set-title`, `h2`: `SlashCommandLine.isName`, what can be typed and completed), else `ShapeSlashCommands.check` refuses the plugin list (`invalid`); two claims to one name for one target (a kind, or every shape) are a `conflict`, and a kind's own command takes the place of an every-shape one of the same name, offered or not. `SlashArguments` is what's typed after the name, trimmed at both ends, adjacent text merged: `runs` (`.text`, `.shape(id, label:)`), `text` (each shape "@" and its label: "near @Groceries"), `shapes` (in order, each once) and `isEmpty`; the module knows no mention, so a pill is a shape only because the host reads it so. Arguments a command doesn't accept leave the line as text and the command never runs (`/lock foo`, `/set-title` given none). A command that takes one shape (`SlashCommand(_:argument:when:kinds:shapes:step:perform:)`: perform only, `argument` `"@shape"` unless it says more) has a rule for which, `shapes: { target, owner, editor in … }`, asked with the shape, the shape the line is on and the editor, which `accepts` can't say: it sees only what was typed, and a pill is a shape of any kind. What's typed must be exactly one shape, a single `.shape` run and no text, that the rule admits; anything else (nothing, text, text and a shape, two shapes, a shape it refuses) is arguments it doesn't accept. It may name the most kinds of shape it takes, `kinds: { registry in … }` (just before `shapes:`; `{ $0.containingKinds.union($0.boardOwningKinds) }` is a command that takes a shape that holds shapes or owns a board; asked of the registry once, `ErasedSlashCommand.kinds(in:)`): a shape of another kind is never admitted, even where the rule would say yes, the rule is asked of shapes of those kinds alone, and a list that ranks the shapes it takes ranks only those (Mentions', below), so a command that takes few of a big board's shapes costs what they are. `ErasedSlashCommand` carries the rule, and the `OfferedSlashCommand` that `commands(for:)` makes, for the shape and the editor it knows, binds it (the editor held weakly: the state holds its own `unowned`, and a list and a text view keep the command), so its `accepts(_:)` has the rule in it and `run`, the typing object's Return and its marks honor it with nothing more; `takesShape`, `admittedKinds` (nil: any kind, or no shape taken) and `admits(_:)` (false for a command that takes no shape) say which shapes a pick may use, for a command that names kinds `admits(_:)` and `accepts(_:)` ask a shape's kind first, from its record anywhere in the file (`editor.shape(inFile:)`: a pill may name a shape on another board; one that isn't there is of no kind). `SlashCommandState` (`editor.slashCommands`, a service; nil without `SlashCommandsPlugin`) says what a shape offers now (`commands(for:)`: its kind's own in builder order, then those over a property it holds, then every shape's that its kind lets in, each whose `when` holds for the shape as it is, an `OfferedSlashCommand`; none for a shape that isn't on the board shown, is kept aside or is read-only: its text can't be edited, so nothing could be typed) and runs one (`run(_:on:with:)`, or by name folded to lowercase): in `undoHistory.group(stepName)`, one step named for the command in words, in title case as a macOS menu has it (`/set-title` is "Set Title", `/turn-into-subboard` "Turn into Subboard": articles, coordinating conjunctions and prepositions of four letters or fewer stay lowercase unless first or last, `OfferedSlashCommand.title`) or by the command's own `step:` (Publishing's `/public` is "Make Public"), none if it commits nothing; false, doing nothing, for a shape that's gone or kept aside, a name the shape doesn't offer now, and arguments it doesn't accept (an `OfferedSlashCommand` is run as it was found, `when` not asked again). It keeps nothing per shape (each kind's commands gathered once, the registry being frozen), so `boardDidChange` is overridden with nothing. A text view takes part by hosting `SlashCommandTyping(over:owner:commands:arguments:)`, which holds the view and the state weakly, belongs to one shape's text (`owner`) and writes the text only through the view: the host tells it what's typed (`didType`), where the text and the caret go (`didChange(isEdit:)`) and asks it first about each key (`takesKey(_:)`, a plain Return), and shows its list as its own (`caretListWindow` returns its `window`), so the list's keys and its closing as the keyboard or the window goes are every caret list's (TextEditing's); `arguments` reads a range of the text as runs (default: plain text); `admittedShapes(at:)`, asked with the index of an `@` just typed, is a `SlashShapeRule` when the line is a command line (`SlashCommandLine`, read with the caret at the `@`) whose command the shape offers now and which takes a shape, else nil (a plain line, a command that takes none, one not offered): the command's `kinds` (nil: any), its `rule` alone (for a shape already known to be of those kinds, as a list that ranks only them asks it) and `admits(_:)` (the kind, then the rule); the host hands the kinds and the rule to the `@` picker. It marks the command as it's typed, as a mention's pill is marked (`EditingTextView.highlights`, in the text's own color so it follows the surface, `SlashCommandStyle.commandFill` 18% and `argumentsFill` 8%, a pill's being 10%): the `/name` on the line the caret is on, while the list lists a command for it (not "No matches") and, with it closed, while the shape offers the command now (`SlashCommandLine.nameRange`), and what it's given in the lighter shade, only if the command accepts it (`/lock now`, which stays text, marks `/lock` alone); so a line Return would run looks unlike one that is only text; nothing is marked in a view that can't be written. A `/` typed (not pasted, not composed, not an undo) on an empty line, at the text's start or right after a line break and with nothing after it, opens the list while the view is editable, no other caret list is open and the shape offers a command; at the start of a line that has text (the line is evaluated whole, so a command chosen there would take that text with it), mid-line, or where nothing is offered, a slash is a slash. The list is `SlashCommandPicker`, headless, built on `CaretList` as Mentions' picker is and shown in a `CaretListWindow` under the `/` (240 wide, rows 24 tall, 8 shown, 4 below, "Commands" to VoiceOver): what's typed after the `/` is the query; an empty one lists every offered command in the order offered, else those whose names it matches ranked with `FuzzyMatcher` (FuzzyMatching's) (best tier first, then as offered), each row the name with its matched characters semibold and the `argument` as its detail, or the one row "No matches" with nothing highlighted; the first is highlighted. It closes when the caret leaves the name (before the `/`, past what was typed, or a selection), the `/` is deleted, what's typed holds what a name can't (whitespace, a line break, a pill, punctuation: ASCII letters, digits and hyphens, matched folded) or is past 40 characters (`SlashCommandPicker.Closing`), and on Escape or ⌘., leaving the `/` as typed; the text's substitutions are off while it's open (`CaretListSubstitutions`). The keys are every caret list's, and Tab, or a click on a row, completes: the `/` and the whole name token it is in (the caret may be in the middle of one) become `/` and the command's name, and a space if it takes an argument and no whitespace follows on its line (a line break doesn't count), one step of the text's undo, running nothing. Return is the list's own: a highlighted command that accepts nothing runs at once if nothing but whitespace follows its name on the line, else Return completes it as Tab does, so its argument can be typed; with nothing highlighted it's a new line, which closes the list. A plain Return (⇧↩, ⌥↩ and ⌘↩ are not) with the list closed, no selection, no text being composed and the caret after the `/` on a line that is `/name` and what follows, where the shape offers a command of that name now (folded to lowercase) and it accepts what follows (trimmed), takes the line's text out of the text, from its `/` to its end but not its line break, leaving the caret at its start on the now empty line, and runs the command; anything else (not a command, one not offered, arguments not accepted) is Return as ever, a new line or a box's commit (a command line runs and doesn't commit; anywhere else commits). The line goes first, as an edit of the person's (undoable, heard by the host through `shouldChangeText` and `didChangeText`, its own steps of the text's undo, its list closed before), because a command that makes the shape read-only (`/lock`) would refuse the text's write after it; the command is asked of the shape when Return is pressed (one not offered by then, or not accepting what was typed, takes nothing out), then run as it was found once the line is gone (`when` isn't asked again, so a command that reads the text still runs). While the shape is edited the line's removal is in the editing session's step and the command's commit closes it, so the command is a step between the typing before and after: the board's Undo takes it back by its name ("Undo Lock"), the typing next, and typing after it is a step of its own; the text's own undo (⌘Z while typing) brings the line's text back and leaves the command done; a command that ends editing (a lock) ends it as the core does. Mentions' `MentionTextView` hosts it (`slashCommands`, made for a view with an owner when the editor has `SlashCommandState`, else nil; its `caretListWindow` is the `@` picker's or the slash list's), so every text where mentions are typed takes slash commands (a note's editor, an arrow's label's (`ArrowLabelEditor`: Return on a command line runs it, where in tldraw it's a new line; an arrow offers `/lock`, Locking's, and `/is-a`, Types', and nothing else of the shipped commands: it has no title, is never public and Moving takes no arrow), the panel's `MentionTextArea`), a pill in a command line is a shape it's given, the `@` picker opened on a line of a command that takes one shape lists only the shapes the command admits, ranking only those of the kinds it names and, with nothing typed, listing every one of those it admits, on every board (`MentionTextView` asks `admittedShapes(at:)` as it opens it: [mentions](mentions.md)), the `@` picker's keys come first while it's open (Return picks the shape; Return then runs the line), opening the picker closes the slash list, and `show(_:)` closes both. Mentions contributes no command and needs no `SlashCommandsPlugin()`: the plugins that offer commands do, since the registry refuses a contribution whose owner isn't installed. `SlashCommandsPlugin()` is right after `ContextMenusPlugin()` in the shipped list; it contributes nothing and claims no key. The commands that ship are Titles' `/title` ([titles](titles.md)), Locking's `/lock` ([locking](locking.md)), Publishing's `/public` and `/private` ([publishing](publishing.md)) and Transform's `/turn-into-<kind>` for each kind a plugin lets shapes turn into ([transform](transform.md)): Subboards' `/turn-into-subboard`, offered on the kinds that offer the container channel (a frame), which have no text to type it in, so it's typeable nowhere in the app yet; Types' `/is-a` ([types](types.md)), on the kinds that hold `is` (a note, and an arrow in its label), taking one choice: `Type` (while the shape can be a type and isn't one: "Make Type") or one of the file's types the shape may be (`TypeIndex.admits`: never the shape itself, one it is already, one that is it in turn, or a pill: "Add Type"); and Moving's `/move-to` and `/move-near` ([moving](moving.md)), on every kind with a box, each taking one shape (a frame or a subboard, by `kinds`; any shape), so the `@` picker on their line lists what they take; every shape's commands are offered in the order of the plugins that contribute them, so where a turnable kind has text it lists before `title` and `lock`, Subboards being before Titles and Locking in the shipped list, and Moving's come last (`MovingPlugin()` is right before `ReorderingPlugin()`): a note lists `title`, `lock`, `public` (or `private`), `is-a`, `move-to`, `move-near`, and an arrow in its label `lock`, `is-a`.
- A command that takes one choice from a list (`SlashCommand(_:argument:when:choices:otherwise:step:perform:)`, told from the other forms by its `choices:` label; `argument` is a `String` with no default, the hint beside the name, and what makes completing write the space; its `accepts` is never true, so the names' list's Return completes it and never runs it): `choices: { owner, editor in [SlashChoice] }` makes the rows when asked (a `SlashChoice` is an opaque `id`, a `title` matched against what is typed and shown, an optional `symbol` and `detail`, a `group` (a line sets off a row whose group differs from the row above it), a `step` (the undo step the pick makes, else the command's) and `isPreferred`, `chip`: a color, passed to the row's `CaretListItem.chip` so the row is a capsule of it, [text editing](text-editing.md)), `otherwise: { typed, owner, editor in SlashChoice? }` the one row to offer when nothing matches (nil leaves "No matches"), and `perform: { owner, choice, editor in … }` runs a pick. `OfferedSlashCommand` has `takesChoice`, `choices()` and `choice(otherwise:)` (bound to the owner and the editor held weakly, as `rule` is); `SlashCommandState.run(_:on:choosing:)` (and by name) runs a pick in `undoHistory.group(choice.step ?? stepName)`, false for a gone or opaque shape and for a command that takes no choice (`run(_:on:with:)` is false for a choice command). The list is `SlashChoicePicker` (SlashChoices.swift, headless, over a `CaretList` with `SlashCommandStyle.choiceMetrics`: 240 wide, rows 28 tall, 8 shown, "Choices" to VoiceOver), and `SlashCommandTyping.choices` is the open one, never together with `picker`, shown in the same `window`, anchored on the `/`. It opens when the name is done and for no other reason: Tab, Return or a click on the command in the names' list writes `/name ` (where a space follows the name already `complete` writes none and puts the caret after it) and opens it, and a whitespace typed after a complete name with nothing but whitespace after it opens it (`didType`); a click into an old line or typing after Escape does not. It asks `choices()` once, when it opens, and keeps the rows while it is open; the query is what is typed from the space to the line's end, trimmed, and an empty one lists every row in the command's order, else `FuzzyMatcher` ranks them (score, then the command's order), the matched letters semibold; none matching is `otherwise`'s row or "No matches" with nothing highlighted, and an empty list with nothing typed is "None". With nothing typed the highlight is on the first `isPreferred` row, else the first; with something typed, the best match. It closes (`SlashChoicePicker.Closing`) when the `/` and the name are not as they were or no whitespace follows the name (`nameChanged`) and when the selection is not a caret or the caret leaves the text from the space to the line's end (`caretLeft`, which is also what a line break typed in it does), and on Escape. Its keys are every caret list's, and `takesReturn()` is false while it is open, so Return, Tab and a click are the window's `pick:`, and `choose` takes the whole line (from the `/` to the line's end, not its break) out of the text as an edit of the person's, then runs the pick: it touches nothing of the view or itself after, since a pick may end this editing (as `/lock` does). With only a quiet row nothing is highlighted, the list takes no key and Return is a new line, which closes it. With the list closed, a plain Return on a choice command's line the shape offers runs the first row whose title is the typed text (folded as `FuzzyMatcher` folds: `FuzzyRanking.exact`), asking `choices()` once, at that Return; none, a new line; only the `/name` of such a line is marked, never what follows it (marking the argument would ask for the rows at every keystroke). `listsChoices(at:)` says whether the line a location is on is a choice command's line the shape offers: where an `@` is a letter, since a pill would be an argument the command cannot take (the host asks it before opening the picker; Mentions does).
