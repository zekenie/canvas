# Jump To

Jump To (⌘K): a palette that goes to a shape by what it's called and where it is; the catalog of titled shapes, its ranking over the containment tree, the palette and its list, picks.

Related: [fuzzy matching](fuzzy-matching.md), [text editing](text-editing.md), [boards](boards.md), [titles](titles.md), [topology](topology.md), [mentions](mentions.md), [selection](selection.md), [keyboard](keyboard.md) ([every topic](../../CLAUDE.md#map)).

In the guide, `docs/plugin-system.md`: [Jump To](../../docs/plugin-system.md#jump-to).

## Architecture

- Jump To (JumpTo, platform, a thing you do: no kind opts into it and nothing imports it, as with `Examples/Reordering`; plugin id `jump-to`, the command's string `jumpTo` being the core's `.jumpTo`) is VS Code's file switcher: name a subboard, skip one, name another two levels down, then the shape, and the list narrows. It looks at titles and the containment tree and never at contents (Find's job). It imports Boards (`editor.follow`), Titles (`registry.title(of:)`), Topology (the tree), Keyboard (⌘K), TextEditing (the field and the list), FuzzyMatching (`PathMatcher`, `FuzzyMatcher`, `BoundedHeap`) and Geometry, and not Mentions: a row's kind name, symbol and tint are `registry.label(of:)`'s, the core's (the one color a kind has in the list, the picker and the Connections tab; a kind that declares no tint is untinted, one with no symbol a dashed square; a shape that has a color of its own is in that, `editor.tint(of:)`, read as the rows are made and kept in none: the catalog has no tint to go stale, a commit that changes a shape remakes an open palette's rows, and so does the file's colors changing, `shapeTintsDidChange`). `JumpToPlugin()` registers a service, `JumpToState` (`editor.jumpTo`, an `@Observable` the palette's view reads: `isOpen`, `query`, `focusRequest`, `top`), and `registrar.command(.jumpTo, shortcuts: [⌘K], isEnabled: session == nil)`, which ends editing (its edit committed), then opens the palette, or, open, bumps `focusRequest` so its field asks for the keyboard again, its text selected; the menu's Go › Jump To… (BoardWindowController's `commands` table, not `textKeys`) is the same command, so it works from a note being edited and a panel's field, where it's the menu bar's key. It changes no document, so `perform`'s undo group is empty and leaves no step. Conformances are in extensions (`EditorService`). It reads the tree from `editor.topology`, which must hear every commit before Jump To does: `TopologyPlugin` comes before `JumpToPlugin` in a plugin list (the shipped list's and `jumpPlugins()`'s do), or paths are empty and nothing is in a container.
- **The catalog** (`JumpToCatalog`, a value `JumpToState` keeps, shaped as Mentions' is): every titled shape on every board the editor can show (the root, and from it down the boards whose owners `registry.ownsShowableBoard` and the file has boards for, each once; none kept aside), named or derived (`registry.title(of:)`: a note's title, a type's among them; a note with none isn't listed, whatever its first line says: that's Mentions'). Entries are plain values (`ShapeID`, the container it's directly in, its title's keys' place in one buffer, its recent rank), the titles beside them, the folded keys of every title back to back in one buffer (`FuzzyMatcher.appendKeys`; swap-remove; packed again when half of it is unused), and a `FuzzyMatcher.Label` per entry made the first time a query reaches it and kept. It keeps no path, no file order and no board: a container's rename or move costs nothing in it. **Lazy**: built the first time the palette opens (`phase`: `unbuilt`, `building(Build)`, `ready`), in slices of `JumpToStyle.buildSlice` (2 ms of the thread's CPU, the clock read every `clockStride` shapes) on the main actor through `editor.scheduler`, the first at once, so a file of a few hundred is ready as ⌘K opens; before then every commit costs a note of its revision. `buildSlices`, `longestBuildSlice` and `buildTime` (release builds too) say how a build went, `entriesRead` (debug builds) how many titles were read, for tests. After: each commit costs what it changed (`hear`): `removed` out, `added` and `changed` less `moved` read again (`refresh`: out if untitled, kept aside, gone or on a board the app can't show (`isOnShowableBoard`: `canShow`'s rule, the core's); a move changes no title), `elsewhere` (a deleted subboard's shapes, a paste's, a write to another board) the same, iterating the smaller of the catalog and the set when a commit only took boards, and the container cache (`nodes`) dropped for those ids; a commit heard out of turn (`heardRevision`, as `TitleIndex`'s) or a file put in place (`boardDidChange` with `isFileReplaced`) reads everything again (now if the palette is open, else at its next opening), and a commit that changes the catalog while it's being built is applied to the part read (`hear`, as Find's index does: what it changed is read now; the shapes on boards not yet read are read when their turn comes, setting one twice being setting it once; the shapes on boards it brought arrive through `elsewhere`; the board being read is walked from the shapes it had when its turn came, but for those the commit touched, read as they are now: `Build.touched`), so continuous commits (an agent's draw, a sync) never keep it from finishing; only a commit heard out of turn or a file put in place starts it over. Showing another board changes none of it, but an open palette with an empty query lists the new board's Nearby.
- **A query** (`JumpToSearch.swift`): `PathMatcher(text)` splits it into pieces. One piece: the titles alone, `FuzzyMatcher.rank` over the catalog's keys in two linear passes (the `@` picker's workload: the tiers, and the typo pass when fewer than 8 matched), the best `JumpToStyle.maxRows` (50) kept in a bounded heap by score, then the recent pick, then the catalog's order. Several pieces: the last piece goes through the same two passes first (every title it matches: a title the whole last group matches is one the last piece matches, as a subsequence, a substring, a word prefix or a prefix, whichever it is, though not always by a typo when 8 titles matched it by the tiers), and only those shapes are scored by their paths with `PathMatcher`'s rows: the row after the chain from the root to a container (`best[g]`: the best score of placing the first g pieces along it) is made once per query for each container that has a candidate under it, from its parent's row through its own title (`advance`; an untitled container is a skip, `nil` label), and a shape then costs `leafScore(after:label:)`, one match per group the last could be in. The chain is followed up through `node(_:)`, a container's parent (`topology.parent(of:)`), title and folded label, found once and kept until a commit changes that shape; no shape's `ancestors(of:)` is asked to rank it, and a loop of containers (a file nothing in the app makes) ends the walk at `JumpToStyle.deepest`. The best are then put in order for the rows by score, the fewer names skipped (`PathMatcher.Match.skipped`), the shallower, the recent pick, and the file's order (`fileOrderKey` from one `snapshot()` taken for the sort, computed only for the ties it breaks): a pick doesn't beat a shallower path. A row is built only for those: its path is Topology's `ancestors(of:)` reversed (outermost first, the root never one), each container by its title or, untitled, by what its kind is called (Boards' `registry.containerName(of:)`, the rule every path names a container by: a board owner's `registry.boardPlaceholder`, else its kind's label; `node(_:)` keeps it), dimmed and never matched (`JumpToSegment.isPlaceholder`: the matcher's `match(path:)` is given an empty name for it); what the query matched in each name comes from `match(path:)` for several pieces and `FuzzyMatcher.match` on the title for one.
- **Rows** (`JumpToRow`): a header, a shape (`JumpToCandidate`: its id, title and matched characters, its path's segments with theirs, the kind's name, its symbol in its tint) or the one row an empty list shows ("No matches", "Nothing to jump to"), and `JumpToRow.listRows` turns them into the list's (`CaretListItem`: the symbol in its tint, the title with matched characters semibold, the path "Alpha › Beta › Gamma" as the detail with its matched characters semibold (`detailMatched`, offsets past each name and its separator) and its placeholders fainter (`detailDimmed`), said as "Checkout, Note, in Alpha › Beta, 2 of 7"); no detail for a shape on the root. An **empty query** lists "Recent" (up to 5 of this window's picks, `recent`, newest first, kept up to 20 and only those still in the catalog) then "Nearby" (up to 5 titled shapes in view on the board shown, nearest the middle of what the host leaves clear of the view, `unobscuredViewport` mapped through `cameraTarget`: a square around the middle grown by four from `JumpToStyle.nearbySearch` until it holds enough, so a board of thousands costs what's around its middle; none before the view has a size).
- **The palette** (`JumpToPalette(editor:onExit:)`, a public SwiftUI view that the window places over the canvas: `JumpToPlugin` gives it to the host's slot for views over the canvas (`registrar.hostOverlay`, after Boards' in the list, so it's over the path: [host slots](host-slots.md)), handed the window's `onExit`, which gives the keyboard back to the canvas): nothing while closed; open, a scrim, a borderless `Button` with a clear label over the whole canvas (an NSButton to the window, so a click lands on it and isn't the canvas's, and a test clicks it), whose action closes the palette and calls `onExit`; and a capsule (`JumpToStyle.width`, 560, by 40: a regular material, a hairline, a shadow) at the top middle, `JumpToStyle.topOffset` (12) below the part of the canvas the host leaves clear taken as it opened (`JumpToState.top`: `unobscuredViewport.minY`, which is the editor's `coveredTop`, which the app sets to the path's pill's height over a subboard), holding `JumpToField`, an `NSViewRepresentable` of JumpTo's own over `JumpToTextView`, an `EditingTextView` in one line (the placeholder "Jump To", 16 points, substitutions off through `CaretListSubstitutions.off`; newlines and tabs pasted in are spaces; Return and Tab with nothing to pick insert nothing). The list is the app's one caret list: `JumpToState.list`, a `CaretList` at `JumpToStyle.metrics` (560 wide, 28-point rows, 10 shown, 6 below the capsule), shown in a `CaretListWindow` made with `anchorRect:` once the field is in its window (`viewDidMoveToWindow`, and `updateNSView` when a palette closed and opened again before the view went), its rect the field's on screen widened by the capsule's padding, so the list sits centered under the capsule at its width; the state's rows are the list's, index for index, and the window follows `list.onChange`. **Keys** are every caret list's (`EditingTextView` while its list is open): ↑ ↓ ⌃P ⌃N and Page Up and Down move (a page is the 10 rows shown, stopping at the ends), Return and Tab pick, and Escape and ⌘. (sent as `cancelOperation:`) close, which `JumpToTextView` takes first (`onEscape`) so the person's closing is told apart from the list closing for another reason. **Closing**: Escape, ⌘., the scrim's click and a pick are the person's, and the canvas has the keyboard after (`onExit`); the field losing the keyboard to anything else (Find's field, the panel's: `onLeave`) or its window resigning key closes the palette without taking the keyboard back; `JumpToState.close()` is the one close, clears the query, and takes the list's window away at once (`onClose`), not when the view goes. A ⌘K with the palette open bumps `focusRequest`, so the field takes the keyboard again, its text selected.
- **A pick** (`pick(row:)`, `pickHighlighted()`, `pick(_:)`; a header, an empty state, a row past the end and a shape that isn't in the file pick nothing): the shape is the latest recent pick, the palette closes, then `editor.follow(id)` (Boards' rule: into a shape whose kind opens its board, else `goTo`), one Back step to where ⌘K was pressed; a frame is fitted (`goTo`'s `reveal`, never forced to 70%, and left as the camera is where it's in view at a readable zoom already). Refused mid-gesture: ⌘K isn't enabled while a session runs, and `goTo` itself does nothing then.
- Another plugin's field taking the keyboard (Find's ⌘F, once its plugin is in the list, whose field is in the panel) closes the palette as its field leaves; the palette takes nothing back.

a rename of a container changes the path of what's in it and reads only it; `transact(on:)` renames on other boards, a pocket deleted taking its boards' shapes out and its undo bringing them back; shapes put in a corral or taken out of one, and a container moved into another, with the paths listed and ranked following; a commit heard out of turn (a service ahead of Jump To that commits while hearing one: `JumpNudger`) reading the file again; a document replaced and a file put in place; a 4,000-shape file read in slices with commits meanwhile applied to what's read (a rename, an added shape, a deleted one, ones on a board not yet read; the build finishing with every titled shape and the commits' changes, none missing), and closing mid-build still finishing it; at most twenty recent picks), RankingTests (one word's titles, the shallower first, then the file's order; a row's name, symbol and tint its kind's label's, a card's declared tint and a box's none; a shape's own tint over its kind's, with CanvasTesting's `Frozen` flag and a contributor's `shapeTints` (`ownTints(_:)`) standing in for a color, and an open palette's rows made again for a commit and for `shapeTintsDidChange`; several pieces in order along a path, skips, the fewer first, "alpha gamma checkout", pieces that are one title's words, the path's names with what matched in each and how the list says them, an untitled container's placeholder dimmed and never matched, typos in a title and a container, a container named only by a word not by a scatter of its letters, ties by recent pick, the 50 best, an empty query's Recent and Nearby, at most five of each, none with no view, the board shown's), PickTests (into a board kind, to any other shape, one Back step, a frame fitted from a camera left at 100% elsewhere, in view already, header and empty rows pick nothing, ⌘K from the canvas's key, ending editing and no step of undo, refused mid-gesture) and PaletteTests (the palette over a real `CanvasView` in an unshown window: ⌘K from the canvas's key equivalents, the capsule 12 points down or below `coveredTop` as it opened, the list's window under it at its width, typing, the keys, Page Down, Tab, Return with nothing to pick, Escape and ⌘., ⌘K again, another view taking the keyboard, the scrim by its button and by `hitTest`, a click on a row, closing and opening again in one turn). ShippedTests' registry report pins the plugin's service, command and key.
- BenchmarkTests' Jump To suite ([benchmarks](benchmarks.md)): a keystroke at 10,000 shapes, one piece and several, the catalog's build in slices, and the upkeep a commit costs.
