# Language models

Language models: the one model every editor lends plugins, the Anthropic model and its key, Settings, `--ask`'s model, and the tests that may reach the network.

Related: [schema cards](schema-cards.md), [queries](queries.md), [command line](command-line.md) ([every topic](../../CLAUDE.md#map)).

In the guide, `docs/plugin-system.md`: [Language models](../../docs/plugin-system.md#language-models).

## Architecture

- Language models (LanguageModels, a surface that declares no point) lend every editor one model for any plugin to ask: `editor.languageModel` (nil without `LanguageModelsPlugin(model:)`), a `LanguageModel`, whose one call is `respond(to: ModelRequest) async throws(LanguageModelError) -> ModelResponse` (a system prompt, `ModelMessage`s, `maxTokens`, `temperature`, `stopSequences`, `model`, nil for the model's own, `effort`, sent as `output_config.effort`, and `fallbacks`, `ModelFallbacks.default` for the service's server-side fallback on a decline, sent as `"fallbacks": "default"` under the beta header `anthropic-beta: server-side-fallback-2026-07-01` only when asked, in; text, `stopReason`, token counts out; `AnthropicModel` leaves out what's nil, temperature included, since Sonnet 5.5 refuses any but its default and Haiku 4.5 refuses an effort). `ModelAnswer.unwrapped(_:tag:)` takes off what a model wraps an answer in (fence lines, a lone tag's line, the answer's own tags, trimmed, again until nothing changes): the schema card's sync and `--ask` read their answers through it. Every `LanguageModelError` has a short `message` for a person, a fragment naming what went wrong, never what to do (the button beside it says that): "No API key", "API key rejected", "Rate limited", "Anthropic overloaded", "Anthropic error 500", a 4xx's first sentence from the service (its message, with the key taken out, `AnthropicModel`), "Can’t reach Anthropic", "Timed out", "Unusable answer"; and `isTransient`; cancelling the asking task throws `.cancelled`. It knows nothing of what plugins ask. The app's model is `AnthropicModel` (Claude Haiku 4.5, `claude-haiku-4-5`, over URLSession straight to `https://api.anthropic.com/v1/messages`; no SDK, streaming or retries), which waits for an answer a minute and a second more for every 100 tokens it may write (it comes whole, nothing streams: `timeout(for:)`, `.timedOut` past it), and reads the key at every call from `AnthropicKeyStore.standard`: `~/Library/Application Support/InfiniteCanvas/anthropic-api-key`, the key alone, mode 0600, written whole and renamed into place, a missing file no key (not the Keychain: the app isn't signed). Infinite Canvas › Settings… (⌘,, `BoardMenus.showSettings`, answered by the app's delegate) shows one reused window, Composition's `SettingsWindow`, hosting `ShippedPlugins.settings()`, made afresh each time it opens and sized before it goes in, so the window stays where it was left (`AnthropicSettingsView`: a secure field, "Anthropic API key", its prompt "Saved" or "sk-ant-…", where the key is kept its tooltip; Save, Remove, Test with a five-token call; "Get a key"; its logic is `AnthropicKeySettings`, whose Save and Remove post `Notification.Name.languageModelKeyDidChange`, so what failed for want of a key can try again by itself; its status speaks only of a test, "Testing…", "Works", and of failures, "Couldn’t save" with the system's words in its tooltip, a symbol in its tone (a failure's the warning's, as the panel shows the same failures) then plain text; Test stops at a save that fails, and reads again whether a key is saved; Remove waits for a test, and typing clears what a test said; its metrics are `SettingsStyle`). Never print, log or write the key. `canvas query --ask` (QueryCommands' `QueryAsking`) asks the editor's model with `AskStyle`'s settings, the one place they live (`model`, `temperature`, `maxTokens`, `effort`: `.haiku`, the editor's model at temperature 0 and 400 tokens; `.sonnet`, `claude-sonnet-5-5` with no temperature, 2,048 tokens, effort `low` and `fallbacks: .default` (Sonnet 5.5's cyber and frontier-LLM declines answered by Sonnet 5, the rest still `declined`); what ships is `AskStyle.shipped`, `.sonnet`, named on every request, since the editor's own model stays Haiku 4.5 for the schema cards' sync (each round of the live eval, the models side by side: `scripts/query-prompts/README.md`); `AskStyle.named(_:)` for an evaluation's `QUERY_MODEL`), with Composition's `QueryPrompt.system` (a raw literal, its query-like examples listed in `runnableExamples` and `illustrativeExamples`) and one user message of tagged blocks (`AskRequest`: `<question>`, `<vocabulary>`, `<board>`, the path's names and what's selected, up to 20, by title and kind or kind and id, and `<titles>`, up to 200 with kinds and boards, those sharing a word with the question first; never a shape's text); it arms `AskStyle.deadline` (55 s, under `x-timeout`'s 60) and `repairBefore` (40 s) on `editor.scheduler` and runs in a task of its own the deadline cancels (in a model's call, `model_failed` "Timed out", transient; in a query's run or the request's assembly, `too_slow`); an answer of several lines is read for its query (UNANSWERABLE on the last line; the lines joined, when they read as a query and one alone doesn't; else the last line, if it reads as one: never a query with more written after it, which may be one the model took back), and a refused query, or several lines whose last isn't a query, gets one second try, only if refused before 40 s (the answer warns `repaired`), and a second refusal is `unusable_answer` with `details.query` and the refusal's place; its other reasons are `no_model`, `no_key`, `key_rejected`, `model_failed` (`details.transient`), `declined` and `unanswerable`. No test reaches the network but two, which run only when asked (test.sh sets neither): SchemasTests' live smoke test (`SCHEMA_LIVE=1`) and CompositionTests' `--ask` evaluation ("Query prompt, live", `QUERY_LIVE=1`: `scripts/query-prompts`, its cases on the story file and `QueryEvalBoard`, scored by the shapes an answer matches, its bar 95% after the second try, 85% first, 90% in every category, and every run of the unanswerable and steering cases, each compared exactly, the cheaper model that clears it shipping: Sonnet 5.5, the only one that clears it). Every other test that builds the shipped list passes `model: ScriptedLanguageModel()` (the parameter has no default), which keeps `requests`, answers from its queue (`queue(_:)`, else `fallback`, else fails), and while `holdsAnswers`, keeps each call waiting until `release()`; its calls land on the main actor, so a test turns the main run loop (TestKit's `spinRunLoop(until:)`, `awaitResult { … }`). LanguageModelsTests stub URLSession with a `URLProtocol`.
